# Project — Real-Time Messaging Platform

**Category:** Backend systems, real-time communication, distributed systems  
**Technologies:** Node.js, WebSockets, Redis Pub/Sub, Docker

Sany built a real-time messaging system using WebSockets and Redis Pub/Sub, containerized with Docker for horizontally scalable delivery.
