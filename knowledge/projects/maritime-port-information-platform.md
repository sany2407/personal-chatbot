# Project — Maritime Port Information Platform

**Category:** Enterprise full-stack application, maritime and e-shipment domain

Sany works on enterprise applications for a vessel and e-shipment platform. His documented responsibilities include backend APIs and microservices for Port Information, Terminal Details, Fleet Compatibility, and User Management.

- Docker-based containerization and CI/CD.
- Next.js frontend integration.
