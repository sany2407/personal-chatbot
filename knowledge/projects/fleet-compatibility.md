# Project — Fleet Compatibility

**Category:** Maritime enterprise application, configurable comparison workflow

Fleet Compatibility is a feature within the maritime Port Information platform intended to help users assess compatibility between a vessel and a berth using their specifications.

## Feature areas from project notes
- Configurable sections, optional subsections, and columns.
- Berth-specific specification values.
- Vessel-specific specification values.
- Comparison of vessel and berth values.
- Rule/type-aware compatibility evaluation.
- Compatibility result display.
- Overrides for berth- or vessel-specific cases.
- Recalculation of affected results after relevant changes.

At a high level, the feature organizes berth and vessel specifications, compares relevant values according to configured rules, and presents a compatibility result. Override functionality supports specific exceptions where available.
